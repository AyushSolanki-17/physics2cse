# physics2cse

`physics2cse` is a free educational repository that explains computing from first principles: measurement, matter, electricity, semiconductors, digital logic, computer architecture, software systems, networks, security, machine learning, AI systems, and large-scale infrastructure.

The project is built around one idea:

> Computing is a connected chain of engineering decisions, from physical reality to intelligent systems.

This is not meant to become a pile of long lecture notes. Each concept should make a learner predict, calculate, test, and connect the idea to what it unlocks next.

## Current State

The repository is in bootstrap. The first working path is **From Charge to Hello World**, beginning with five connected lessons:

1. Measurement, models, and units
2. Matter and electric charge
3. Electric fields and potential
4. Voltage, current, and resistance
5. A first circuit model

## Development

Install dependencies:

```sh
npm install
```

Run local checks:

```sh
npm run validate
npm test
npm run build
```

Start the documentation site:

```sh
npm run dev
```
